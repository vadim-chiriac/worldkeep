# Two allied countries

Minimal KERNEL v0.11 example:

- Avelor and Brannoch are `entity` artifacts typed as `place/country`.
- The River Lume is an `entity` typed as `place/river`.
- Their alliance is a two-member `relation`, so the graph can draw it as an edge.
- The river separating them is a three-member `relation`, so the graph reifies it as a small node with three spokes.
- `views/political.yaml` is a non-canon view configuration.
